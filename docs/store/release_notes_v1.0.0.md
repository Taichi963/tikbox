# リリースノート v1.0.0

## Google Play 用（500文字以内）

```
LiveVoice Box v1.0.0 — 初回リリース

ライブ配信コメントのリアルタイム読み上げ、ギフト効果音・バイブレーション、バックグラウンド再生、コメントフィルタリング、セッション統計を搭載した初版をリリースします。

主な機能:
- 公開LIVEコメントをリアルタイム読み上げ（速度・ピッチ・ボイス調整対応）
- ギフト受信時の効果音と段階的バイブレーション
- バックグラウンド・スクリーンオフ中も読み上げ継続
- NGワード・ユーザーブロック機能
- セッション統計とギフトランキング
```

## App Store 用

App Store の「このバージョンの新着情報」欄は通常 4000 文字以内だが、短いほど読まれやすい。

```
LiveVoice Box v1.0.0 — 初回リリース

ライブ配信コメントのリアルタイム読み上げ、ギフト効果音・バイブレーション、バックグラウンド再生、コメントフィルタリング、セッション統計を搭載した初版をリリースします。

主な機能:
- 公開LIVEコメントをリアルタイム音声読み上げ（速度・ピッチ・ボイス調整対応）
- ギフト受信時の効果音と段階的バイブレーション（金額に応じて3段階）
- バックグラウンド・スクリーンオフ中も読み上げ継続（バックグラウンド音声使用）
- NGワード（固定+ユーザー追加）とユーザーブロック機能
- セッション統計・ギフトランキング・ハイライト記録
```

---

## 注意事項

- 「新着情報」欄には施行日・ポリシー変更等のリリース固有情報は記載しない（初版のため変更履歴なし）
- 上記文面は `[提出時に確定]` 等のプレースホルダーを含まないため、そのまま貼り付けて使える
- バージョン番号（v1.0.0）は App Store Connect / Play Console のビルド設定と一致していること
