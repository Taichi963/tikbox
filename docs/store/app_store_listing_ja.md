## 説明文

```
LiveVoice Boxは、ライブ配信中の公開コメントを音声で確認しやすくする、配信者向けの非公式サポートツールです。

■ 主な機能

【コメント読み上げ】
公開LIVEコメントをiOSの音声合成でリアルタイムに読み上げます。読み上げ速度・ピッチ・音量の個別調整、コメント用とギフト用への別ボイス設定、ユーザー名読み上げのON/OFFが可能です。

【ギフト通知音・バイブレーション】
ギフト受信時に効果音とバイブレーションでお知らせします。ギフトの金額に応じてバイブレーション強度が変化します。効果音プリセット（バランス・ド派手・やさしい）から好みに合わせて選択できます。

【バックグラウンド再生】
ユーザーが開始した読み上げセッション中は、アプリをバックグラウンドにしても音声合成が継続します。

【コメントフィルタリング・ブロック】
固定NGワードと追加NGワードでコメントをフィルタリングします。特定ユーザーをブロックしてコメントの表示・読み上げを防ぐことができます。不適切なコメントの通報文をアプリ内でまとめてコピーできます。

【セッション統計・ハイライト】
セッション中のコメント数・ギフト数・フォロー数・いいね数を集計し、ギフト上位3名のランキングと注目ハイライトを記録します。

■ ご注意

本アプリはTikTokまたはByteDanceの公式アプリではなく、両社から承認・スポンサーを受けたものではありません。TikTokのログイン情報・パスワード・既存のブラウザCookieは取得しません。配信サービスの仕様変更や端末環境により、接続や読み上げを利用できない場合があります。
```
