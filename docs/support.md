## About LiveVoice Box

LiveVoice Box is an unofficial live-stream support tool. It is not affiliated
with, endorsed by, approved by, or sponsored by TikTok, ByteDance, or any other
live-streaming platform.

The app reads public LIVE comments aloud, provides gift feedback, and includes
local comment filtering and user-blocking tools. Connection availability is not
guaranteed and may vary with stream status, network conditions, service
changes, operating-system restrictions, or device settings.

## Comment Reports

For an inappropriate public LIVE comment:

1. Open the three-dot menu on the comment.
2. Select the report action and reason.
3. Review the prepared report.
4. Copy the recipient, subject, and report body.
5. Paste them into an email app and send the report to
   zeb0kui3ackwv4pft1us@gmail.com.

The prepared report contains:

- report reason
- public display name
- public LIVE user reference type and value
- comment text
- time received

The prepared report does not include cookies, `ttwid`, a device ID, complete
internal logs, login credentials, or authentication information. LiveVoice Box
does not send the report automatically. Reports received at the support email
are reviewed by the operator.

## Comment Filtering And Blocking

- Fixed and user-added blocked words are checked before a matching comment is
  displayed, played as a comment sound, or added to text-to-speech.
- User-added blocked words are stored locally on the device.
- A block based on a public LIVE `uniqueId` is stored locally until the user
  removes it, clears the app's storage, or uninstalls the app.
- If only a display name is available, the block applies to the current
  connection session and is not saved.
- Blocked users can be unblocked from the app's detailed settings.

## Login And Cookies

LiveVoice Box does not request TikTok passwords, read existing browser or
TikTok app cookies, or use a WebView login.

The bundled LIVE connection library may obtain a temporary service-issued
`ttwid` cookie through an unauthenticated request for the public LIVE
connection. It is not a user login credential and is not stored by LiveVoice
Box in SharedPreferences or an app database.

## Local Data Removal

Users can remove saved stream IDs, custom blocked words, and blocked users
through the available app controls. Users can remove all locally stored app
settings and history by clearing the app's storage through the operating-system
settings or uninstalling the app.
