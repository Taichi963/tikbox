# Privacy Notes - LiveVoice Box

LiveVoice Box is an unofficial live-stream support tool. It is not affiliated
with, endorsed by, or sponsored by TikTok, ByteDance, or any live-streaming
platform.

## Data Used By The App

- Stream ID: Used to start the selected public live connection.
- Live comments: Used for comment display and text-to-speech playback.
- Gift events: Used for gift sound, vibration, and gift-related feedback.
- Settings: Used to restore TTS, sound, vibration, and app preferences.
- Username history: Used to show recently used stream IDs in the app.

## Local Storage

- Settings are stored on the device using local app storage.
- Username history is stored on the device using local app storage.
- LiveVoice Box does not store settings or username history on a
  LiveVoice Box-operated server.

## Network Communication

- The entered stream ID is sent to the live connection endpoint to start the
  selected public live connection.
- Live comments and gift events are received from the live connection and are
  processed inside the app for reading, sound, and vibration.
- LiveVoice Box does not send settings or username history to a
  LiveVoice Box-operated external server.

## Login And Cookies

- The app does not ask for account login credentials.
- The app does not collect passwords.
- The app does not collect cookies, browser cookies, or app cookies.
- The app does not include WebView login for cookie extraction.

If a backend server, analytics, external TTS, or account feature is added in the
future, this document and the store privacy disclosures must be updated before
release.
