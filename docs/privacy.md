# Privacy Notes

TikBox is an unofficial TikTok LIVE support tool. It is not affiliated with,
endorsed by, or sponsored by TikTok or ByteDance.

## Data Used By The App

- TikTok ID: Used to connect to the selected TikTok LIVE stream.
- LIVE comments: Used for comment display and text-to-speech playback.
- Gift events: Used for gift sound, vibration, and gift-related text-to-speech.
- Settings: Used to restore TTS, sound, vibration, and app preferences.
- Username history: Used to show recently used TikTok IDs in the app.

## Local Storage

- Settings are stored on the device using local app storage.
- Username history is stored on the device using local app storage.
- TikBox does not store settings or username history on a TikBox-operated server.

## Network Communication

- The entered TikTok ID is sent to TikTok LIVE connection endpoints to start the
  LIVE connection.
- LIVE comments and gift events are received from the LIVE connection and are
  processed inside the app for reading, sound, and vibration.
- TikBox does not send settings or username history to a TikBox-operated
  external server.

If a backend server or additional analytics are added in the future, this
document and the store privacy disclosures must be updated before release.
